Liv_Synch_Loader is a C# folder synchronization tool designed to detect and resolve synchronization differences between directories.

The project originally started as a way to synchronize a Minecraft world between two computers. As development continued, it evolved into a more general-purpose synchronization utility that can work with different folders and file structures.

Liv_Synch_Loader can compare source and destination folders, detect missing or outdated files, preserve nested folder structures, and synchronize files between locations.

The tool can also be used alongside cloud services such as OneDrive. Rather than replacing cloud storage, Liv_Synch_Loader supplements it by giving the user direct control over which folders are compared, which direction synchronization occurs, and when files should be transferred.

The goal of the project is to make folder synchronization transparent and controllable: the user can see whether folders are synchronized, choose the source and destination, reverse the synchronization direction, and synchronize local or cloud-backed folders.
