# Liv_Synch_Loader

> **Under udvikling** – projektet er stadig en prototype.

Liv_Synch_Loader er et simpelt filsynkroniseringsprogram skrevet i **C#** til **Windows**.

Projektet er udviklet som et personligt læringsprojekt med fokus på filhåndtering, synkronisering og forbedring af mine programmeringsevner.

## Funktioner

- Synkronisering af filer mellem mapper.
- Automatisk kopiering af nye og opdaterede filer.
- Mulighed for at skifte synkroniseringsretning.
- Oprettelse af lokale backups.
- Visning af synkroniseringsstatus.

## Brug

Programmet styres gennem en simpel konsolmenu.

| Tast | Funktion |
|---|---|
| A | Synkroniser filer |
| B | Vælg kildemappe |
| C | Opret backup |
| D | Skift synkroniseringsretning |
| F | Vis menuen igen |
| Q | Gem nødkopi og afslut |

## Fremtidige forbedringer

- Bedre håndtering af filkonflikter.
- Forbedret fejlhåndtering.
- Flere tests og optimering af koden.
- Gemme ens valgte mapper.

## Bemærk

**Programmet er stadig under udvikling og er ikke færdigtestet.** Der kan derfor forekomme fejl eller manglende funktionalitet.

Det anbefales kun at bruge testfiler indtil videre.
